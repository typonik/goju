# Быстрый запуск

1. Установите Python 3.12 и зависимости:

   ```bash
   pip install -r requirements.txt
   ```

2. Скопируйте `.env.example` в `.env` и заполните:
   - `BOT_TOKEN` — актуальный токен от BotFather;
   - `CHANNEL_ID` — ID канала;
   - `ADMIN_IDS` — числовые ID администраторов через запятую.

   На хостинге значения можно задать в Environment. Токен в Git не загружайте.

3. Добавьте бота администратором канала с правом одобрения заявок.

4. Проверьте токен и запустите одну копию бота:

   ```bash
   python check_connection.py
   python run.py
   ```

5. Отправьте `/start` боту с аккаунта администратора. Создайте приветствие,
   настройте задержку и кнопки, проверьте предпросмотр и включите приветствие.

Для сообщений через неделю пользователь должен запустить бота или написать ему.
Одного вступления в канал недостаточно. Отключение сообщений — `/stop`.

При обновлении сохраняйте `.env`, JSON и базы на постоянном диске.
Подробности: [README_DELIVERY.md](README_DELIVERY.md).
