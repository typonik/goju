# Telegram Бот Приветствия

Полнофункциональный Telegram бот для автоматического приветствия новых подписчиков канала с расширенной админ панелью.

## 🚀 Возможности

### 📝 Управление приветствиями
- Создание и редактирование приветственных сообщений
- Настройка задержки отправки (от 0 секунд до 3 минут)
- Добавление URL кнопок к сообщениям
- Замена ссылок в тексте
- Активация/деактивация сообщений

### 👥 Прием подписчиков
- **Автоприем**: автоматическое принятие с настраиваемой задержкой (30 сек - 24 часа)
- **Ручной прием**: прием по количеству, дате или ссылке
- **По расписанию**: прием в определенное время

### ⚙️ Настройки
- Управление администраторами
- Настройка канала
- Смена токена бота

### 📊 Статистика и рассылка
- Статистика подписок
- Массовая рассылка сообщений

## 🛠 Установка и запуск

### Требования
- Python 3.8+
- Telegram Bot Token
- ID канала

### Установка зависимостей
```bash
pip install -r requirements.txt
```

### Настройка
1. Убедитесь, что токен бота и ID канала указаны в `config.py`
2. Добавьте бота в канал как администратора
3. Убедитесь, что у бота есть права на:
   - Отправку сообщений
   - Принятие заявок на вступление
   - Управление участниками

### Запуск
```bash
python run.py
```

## 📋 Команды

- `/start` - Запуск бота (для админов открывает админ панель)
- `/admin` - Открыть админ панель

## 🔧 Админ панель

### Главное меню
- **Приветствия** - управление приветственными сообщениями
- **Прием подписчиков** - настройка способов приема
- **Настройки** - управление админами и конфигурацией
- **Статистика** - просмотр статистики
- **Рассылка** - массовая отправка сообщений

### Управление приветствиями
1. Нажмите "Приветствия" в главном меню
2. Выберите "Добавить" для создания нового приветствия
3. Отправьте текст приветственного сообщения
4. Выберите задержку отправки
5. Добавьте URL кнопки (опционально)

### Прием подписчиков

#### Автоприем
1. Перейдите в "Прием подписчиков" → "Автоприем"
2. Включите/выключите автоприем
3. Настройте задержку приема

#### Ручной прием
1. Перейдите в "Прием подписчиков" → "Ручной прием"
2. Выберите способ приема:
   - По количеству
   - Принять всех
   - По дате
   - По ссылке

#### По расписанию
1. Перейдите в "Прием подписчиков" → "По расписанию"
2. Введите время в формате ЧЧ:ММ

### Настройки
- **Админы**: добавление/удаление администраторов
- **Канал**: просмотр настроек канала
- **Токен**: управление токеном бота

## 🗄 База данных

Бот использует SQLite для хранения:
- Приветственных сообщений
- Списка администраторов
- Настроек бота
- Статистики
- Очереди ожидающих пользователей

## 🔒 Безопасность

- Только администраторы могут управлять ботом
- Главный администратор не может быть удален
- Токен бота скрыт в интерфейсе

## 🐛 Устранение неполадок

### Бот не отвечает
1. Проверьте правильность токена
2. Убедитесь, что бот добавлен в канал
3. Проверьте права бота в канале

### Ошибки при принятии пользователей
1. Убедитесь, что бот имеет права на принятие заявок
2. Проверьте, что канал настроен на одобрение заявок

### Проблемы с базой данных
1. Убедитесь, что у бота есть права на запись в директорию
2. Проверьте целостность файла базы данных

## 📞 Поддержка

При возникновении проблем проверьте:
1. Логи бота в консоли
2. Настройки канала
3. Права бота

## 🔄 Обновления

Для обновления бота:

2. Обновите код
3. Перезапустите бота
