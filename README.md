# Telegram-бот приветствий и рассылок

Приветствия для участников канала, приём заявок и рассылки в личные диалоги.
Основная реализация — `simple_working_bot.py`, команда запуска — `python run.py`.

## Возможности

- Текст, фото, видео и документы в приветствиях; задержки до 30 дней.
- Форматирование Telegram, скрытые ссылки и Premium-эмодзи в тексте и подписях.
- Синие, зелёные и красные URL-кнопки с Premium-иконками.
- Ручные и ежедневные рассылки, предпросмотр и сохранение прогресса.
- Обработка лимитов, `retry_after`, отписок и блокировок.
- Восстановление очередей после перезапуска без слепого повтора неизвестных отправок.
- Ручной и автоматический приём заявок, расписание по московскому времени.

## Установка и запуск

Python 3.12:

```bash
pip install -r requirements.txt
```

Скопируйте `.env.example` в `.env` и заполните `BOT_TOKEN`, `CHANNEL_ID`,
`ADMIN_IDS` (числовые ID администраторов через запятую). На хостинге можно задать
их в Environment — эти значения имеют приоритет над `.env`.
Токены не нужно вставлять в исходники или коммитить в Git.
Добавьте бота администратором канала с правом одобрения заявок.

```bash
python check_connection.py
python run.py
```

Первая команда проверяет только токен через `getMe`. При запуске бот также
проверяет токен и завершает процесс с ошибкой, если Telegram его отклоняет.
Запускайте одну копию с одним токеном. Старые `bot.py`, `simple_bot.py`,
`working_bot.py` и файлы `copy.py` не являются точкой запуска обновления.

## Получатели

Пользователь должен нажать «Запустить», отправить личное сообщение боту
или предоставить право записи средствами Telegram. Тогда сообщения могут
приходить и через неделю. Членство в канале само по себе этого права не даёт.
Заявка даёт временное окно связи — до пяти минут, пока её не обработали.

- `/start` — включить сообщения; для администратора открывает панель.
- `/admin` — открыть панель администратора.
- `/stop` или `/unsubscribe` — отключить рассылки и отложенные сообщения.

Для Premium-эмодзи нужен Telegram Premium владельца бота для прямых сообщений
либо соответствующий доступ через Fragment. Premium получателя это не заменяет.
При явном отказе Telegram неподдерживаемое оформление заменяется обычным.

## Обновление и данные

Перед обновлением остановите бота и сохраните резервную копию данных и `.env`.
Не заменяйте рабочие JSON и базы демонстрационными файлами.
Настройте постоянную папку через `BOT_DATA_DIR` или используйте постоянную папку
приложения. Полный перечень состояния: [README_DELIVERY.md](README_DELIVERY.md).

Ранее загруженные файлы состояния могут оставаться в истории Git. Новые локальные
данные, токены, базы, логи и резервные копии исключены через `.gitignore`.

## Проверки

```bash
python -m unittest discover -s tests -p test_delivery.py
```

49 регрессионных проверок: недельные задержки, восстановление прогресса,
получатели и отписки, оформление и локальные HTTP-сценарии ошибок Telegram.
Тесты не отправляют сообщения пользователям. Живая доставка на хостинге
проверяется отдельно.

Инструкции по оформлению, ограничениям и эксплуатации:
[README_DELIVERY.md](README_DELIVERY.md).
